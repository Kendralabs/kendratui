> 🧭 **Kendra CLI — Doc 1: Vision, Positioning & Product Principles**

## 1. Vision
Kendra CLI should evolve into a high-trust, open, agentic software-development platform that combines a **dual-agent (planner/executor) kernel** with Claude Code's harness discipline, OpenCode's flexibility, Factory.ai's workflow breadth, and Gemini CLI's advances in policy, memory governance, session navigation, extension packaging, and agent interoperability.

## 2. Positioning
- Claude Code: harness discipline
- OpenCode: model-agnostic routing + flexibility
- Factory.ai: workflow breadth
- Gemini CLI: policy-as-config, memory inbox review, extension packaging, JSONL streaming, browser automation, A2A delegation

## 3. Product principles
- Preserve kernel (explicit planner/executor)
- Make trust visible
- Separate runtime from experience
- Optimize for bounded autonomy
- Prefer portable standards (MCP, A2A-style, OTEL)
