# 6 — Memory, Context & Session Model

Source: https://app.notion.com/p/c73a2a2dc13e427ab19c87270abaf80f

## Project instruction model
- `KENDRA.md` upward traversal
- `kendra.jsonc` layered configuration; inspectable effective config

## Four-tier memory
Short-term · Mid-term · Long-term (KCG-grounded) · Inbox (proposals)

## Inbox review & structured patching
Memory writes become proposals; approved changes applied via structured patching.

## Context discipline
Adaptive compaction; event reminders; output offloading; visible context budgets.

## Session & checkpoint model
Chaptered + branchable sessions; checkpoints + shadow commits; `/rewind` moves code + conversation together; loop detection.
